# 2026-11-19

## Done

- Migrated the gate scripts from `.mjs` to TypeScript (`scripts/check-docs.ts`, `scripts/verify-package.ts`, `scripts/verify-release-tag.ts`), run them directly with `bun` from `package.json`, added `scripts` to the `tsconfig.json` `include`, and covered the scripts with `tsc --noEmit`.
- Removed `publishConfig.provenance`: npm cannot generate provenance for a local publish, so a manual `npm publish` failed with `EUSAGE`.
- Added `if: vars.NPM_OIDC_READY == 'true'` to the `publish` job in `publish.yml`; the first release is skipped while the variable is unset and is instead bootstrapped manually.
- Translated all documentation, code comments, script output, and CI messages to English, and added `docs/engineering/writing-style.md`.
- Synced the docs: `build-and-release`, `release-checklist`, `package-contract`, the `postmortem` pitfall checklist, `AGENTS.md`, and `README.md`.

## Decisions

- Gate scripts run through `bun` rather than `node --experimental-strip-types`: Bun is already the only package manager and runtime, so it runs TypeScript without a build or a flag.
- The scripts keep `node:` built-in imports: they only run during development and are not part of the library artifact, so they do not affect the `platform: 'neutral'` contract.
- The first release uses the "manual publish -> bind Trusted Publisher -> enable the variable" bootstrap flow, matching the downstream `tweet-sdk`, so a tag push never publishes to a package that does not exist yet.
- Project text is English only. The rules live in `docs/engineering/writing-style.md`; runtime data keeps its original language.
