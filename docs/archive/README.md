# Archive

Documents that no longer apply but still hold reference value move into this directory.

## Rules

- Archived files keep their original file name and gain a line at the top: `> Archived: <date>, reason: <reason>`.
- Main documents do not link to archived content; state the conclusion directly instead.
- `docs/README.md` does not register archived files one by one.
- Archiving is not deleting: only remove a file from the repository once nothing depends on it.
