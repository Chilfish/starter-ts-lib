# Security policy

## Supported versions

Only the latest released version receives security fixes.

## Reporting a vulnerability

Report privately through GitHub Security Advisories:

<https://github.com/Chilfish/starter-ts-lib/security/advisories/new>

Do not open a public issue and do not disclose exploitation details in a pull request.

Include in the report:

- Affected version
- Reproduction steps or a minimal reproduction repository
- Impact and possible exploitation path
- Your suggested fix direction (optional)

## Response

- Confirm the reproduction and assess the impact after receiving the report.
- Ship the fix as a patch release and describe the scope in the CHANGELOG.
- Record the incident under [postmortem](./docs/postmortem/README.md) after the fix lands.

See [docs/engineering/security.md](./docs/engineering/security.md) for the project's security rules.
